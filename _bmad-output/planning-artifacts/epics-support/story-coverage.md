## Dépendances et découpage

Epic 1 : 1.1 → 1.2 → 1.3. Epic 2 : 2.1 → 2.2 → 2.3 → 2.4 → 2.5, après epic 1. Epic 3 : 3.1 → 3.2 → 3.3 → 3.4 → 3.5 → 3.6 ; 3.7 réutilise 2.4/2.5 et 3.1/3.2 ; 3.8 suit 3.1/3.7. Chaque dépendance opérationnelle vise une story précédente. Les références vers une future extension délimitent ce qui n’existe pas encore, elles ne conditionnent pas le succès courant.

Le domaine Tâche n’existe pas avant 3.3 ; cette même story introduit tous les garde-fous de clôture. Les sociétés et les échanges contacts fonctionnent avant les opportunités. Aucune table future n’est créée au scaffold. Le chevauchement annuaire/pipeline est l’ajout de relations prévu, pas deux moteurs métier ; pipeline/tâches/relances sont regroupés dans le même epic pour limiter les modifications répétées des commandes communes.
