# Contrat de construction du POC CRM

La [spécification](SPEC.md) rassemble huit capacités et adopte le PRD, l’UX, l’architecture et les décisions déléguées nécessaires à leur construction. La [couverture](coverage.md) relie les exigences aux capacités.

Les deux passes de contrôle initiales sont terminées. Q1–Q6 ont ensuite été précisés par délégation et intégrés comme compagnon ; Q7 reste un prérequis d’environnement, sans achat ni cible implicite.

Le [découpage final](../../planning-artifacts/epics.md) comporte trois epics et 16 stories. Le [contrôle de préparation](../../planning-artifacts/implementation-readiness.md) valide le plan avec réserve opérationnelle Q7. Aucun code applicatif n’est produit dans cette phase.
